# Name and Discription : FITLOG

A simple gym app to browse exercises and build a daily workout plan.

## Technologies Used

- Next.js
- TypeScript
- Tailwind CSS

## Key Features

1. Browse a library of exercises covering major muscle groups.
2. Filter or identify lifts by target areas like chest, back, and legs.
3. Add and save specific exercises to a daily plan.
4. View details for each exercise including reps, calories, and ratings.
5. Access saved routines and track daily sets in one place
